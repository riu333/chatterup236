# ChatterUp

ChatterUp is a real-time chat application built using Node.js, Express.js, Socket.io, and MongoDB.

## Features

- Real-time messaging
- User model and message model
- Socket.io based communication
- MongoDB database connection
- Responsive frontend using HTML, CSS, and JavaScript

## Tech Stack

- Node.js
- Express.js
- Socket.io
- MongoDB
- Mongoose
- HTML
- CSS
- JavaScript

```bash
npm install
npm start
